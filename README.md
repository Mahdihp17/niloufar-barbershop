# سایت آرایشگاه مردانه نیلوفر

نسخه فعلی یک فرانت‌اند استاتیک تک‌صفحه‌ای است و برای انتشار مستقیم روی GitHub Pages آماده شده است.

## فایل‌ها

- `index.html` — ساختار صفحه
- `styles.css` — طراحی شیشه‌ای و ریسپانسیو
- `app.js` — منطق رزرو آزمایشی، جلوگیری از رزرو تکراری در مرورگر و اعتبارسنجی فرم

## اجرای محلی

می‌توانید فایل `index.html` را مستقیم باز کنید. برای رفتار نزدیک‌تر به محیط واقعی بهتر است از Live Server در VS Code استفاده کنید.

## انتشار روی GitHub Pages

1. در GitHub یک Repository جدید بسازید. مثلاً: `niloufar-barbershop`
2. فایل‌های `index.html`، `styles.css` و `app.js` را داخل ریشه Repository آپلود کنید.
3. وارد Repository شوید و از منوی `Settings` به بخش `Pages` بروید.
4. در قسمت `Build and deployment`، گزینه Source را روی `Deploy from a branch` قرار دهید.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذارید و Save کنید.
6. بعد از فعال شدن Pages، لینک سایت به شکل زیر خواهد بود:
   `https://USERNAME.github.io/niloufar-barbershop/`

اگر نام Repository را `USERNAME.github.io` بگذارید، آدرس اصلی شما می‌تواند مستقیماً `https://USERNAME.github.io/` باشد.

## محدودیت مهم نسخه فعلی

GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند. بنابراین دو قابلیت زیر در نسخه فعلی فقط به شکل نمایشی/محلی هستند:

1. **جلوگیری از رزرو تکراری بین همه کاربران:** الان رزرو در `localStorage` مرورگر ثبت می‌شود. یعنی فقط همان دستگاه می‌فهمد آن ساعت گرفته شده است. برای قفل واقعی بین همه کاربران باید یک دیتابیس یا API مرکزی داشته باشیم.
2. **ارسال اطلاعات رزرو به تلگرام:** توکن Bot تلگرام نباید داخل `app.js` قرار بگیرد چون هر کاربری می‌تواند آن را ببیند. باید یک بک‌اند یا Serverless Function امن ساخته شود و فرانت‌اند فقط درخواست رزرو را به آن ارسال کند.

در `app.js` متغیر `BOOKING_API_URL` از قبل برای اتصال مرحله بعد آماده شده است.

## پیشنهاد مرحله بعد

برای نسخه نهایی می‌توان از یکی از این روش‌ها استفاده کرد:

- Supabase برای دیتابیس + یک Edge Function برای ارسال تلگرام
- Firebase برای دیتابیس + Cloud Function
- Cloudflare Workers / Vercel Functions برای API + یک دیتابیس سبک

در مرحله بک‌اند، رزرو باید به‌صورت Atomic بررسی و ثبت شود تا دو نفر نتوانند همزمان یک ساعت را بگیرند.

## تغییر قیمت محصولات

قیمت محصولات هم در `index.html` و هم در گزینه‌های فرم نوشته شده‌اند. کافی است متن قیمت‌ها را جایگزین کنید.

## تغییر ساعت‌های رزرو

در `app.js` این بخش را پیدا کنید:

```js
const TIME_SLOTS = ["18:00", "19:00", "20:00", "21:00", "22:00", "23:00"];
```

می‌توانید هر ساعت دیگری اضافه یا حذف کنید.

## QR Code

وقتی آدرس نهایی GitHub Pages یا دامنه اختصاصی مشخص شد، می‌توان برای همان URL یک QR Code اختصاصی ساخت و در کارت ویزیت، اینستاگرام یا داخل خود سایت قرار داد.
